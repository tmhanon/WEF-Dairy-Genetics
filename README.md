# README

Alexander S. Hopkins and Tristan M. Hanon

## Overview

This repository contains the analysis code and Quarto files used to produce the 
paper "Milking Genetic Potential: Structural Change in the U.S. Dairy Industry"
by Alexander S. Hopkins and Tristan M. Hanon.
